SSC CGL PDF Library

1. Extract this ZIP.
2. Put index.html in the same folder as your PDF files.
3. Keep the PDF filenames exactly the same as shown on the page.
4. Double-click index.html to open it in your browser.

This is a simple offline webpage with only PDF search, subject filters, open and download links.
No analysis, charts, trackers, accounts or installation required.
The PDF files are not included in this ZIP.
